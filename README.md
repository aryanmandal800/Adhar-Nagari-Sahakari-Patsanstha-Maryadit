# Adhar Nagari Sahakari Patsanstha Website

Premium responsive React + Vite website concept using the supplied society logo and a navy-blue/red visual identity.

## Run locally
1. Install Node.js 18+
2. Open this folder in a terminal
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite

## Production build
Run `npm run build`; output is generated in `dist/`.

## Important content notes
- The official website URL supplied was https://adharnagari.com/. It did not respond during reference inspection, so this concept uses conservative placeholder copy rather than inventing rates, branch addresses, registration details, or contact numbers.
- The loan products are presented as enquiry categories, not confirmed products or offers.
- EMI calculator is illustrative only; actual rates and terms must be confirmed with the society.
- Replace placeholder contact details and social links with verified society details before publishing.
